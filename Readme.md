## About

AI/ML Engineer building production-grade AI systems. I work across the full stack of modern AI — agentic pipelines, RAG architectures, LLM orchestration, and computer vision — with a focus on reliability, not just demos.

Currently at **Clicode**, I architected a conversational financial copilot that replaced a failed standard RAG approach with a structured agentic pipeline: an intent router, dual retrieval paths (Superlinked SIE for qualitative + SQL tool registry for quantitative), a LangGraph orchestrator with a hard 3-round production cap, full audit logging on every decision, and a channel-aware output adapter for Web and WhatsApp.

Before that, at **Tuvoc Technologies**, I built a production RAG pipeline using Whisper for transcription, benchmarked embedding models across OpenAI, Instructor, and MiniLM, and tuned vector DB parameters for optimal retrieval. Prior to industry, I spent 6 months at **ISRO's Space Applications Centre** building a deep learning pipeline for land cover change detection on Sentinel-2 satellite imagery.

I care about clean architecture, systems that hold under real load, and AI that's actually reviewable by humans.

## Flagship Projects

### 🏦 Conversational Financial Copilot (Web + WhatsApp)
> `🚀 In Production` · LangGraph · FastAPI · Superlinked SIE · PostgreSQL · Docker

Standard RAG failed on structured financial data — balance sheets don't chunk, hierarchies don't flatten, and LLMs hallucinate when math is involved. Rebuilt from scratch with a fully agentic architecture:

Intent router classifies domain, extracts entities (month, year, client), injects only relevant tool schemas. Dual retrieval: Superlinked SIE (Docling table parsing + temporal encoder + cross-encoder reranking, self-hosted) for qualitative; SQL tool registry for quantitative where LLM emits JSON tool calls and backend executes. LangGraph orchestrator with hard 3-round cap. Full audit logging on every tool call, retrieval, and LLM decision. Channel-aware output adapter: charts + deep links on Web, plain text + PNG tables on WhatsApp.

`LangChain` `LangGraph` `FastAPI` `Pinecone` `FAISS` `ChromaDB` `Docker` `PostgreSQL` `WhatsApp Business API` `Superlinked`

### 🛸 Land Cover Change Detection @ ISRO
> `✅ Completed` · ISRO SAC · U-Net · ResNet-34 · Sentinel-2

Deep learning pipeline for semantic segmentation of Sentinel-2 Level-1C satellite imagery to detect land cover changes over the Ahmedabad region. Trained on OSCD dataset, adapted to custom-labeled data. Preprocessing: RGB band handling, GeoTIFF conversion, normalization. Inference generates change masks for monitoring environmental and urban transformations.

`PyTorch` `U-Net` `ResNet-34` `GeoTIFF` `Sentinel-2` `OSCD`
